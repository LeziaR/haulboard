# Haulboard privacy policy

Last updated: 2026-11-01

Haulboard is an Atlassian Forge app for Jira Cloud.

- **What it reads:** Jira issues in the projects where it is used (labels, summaries, dates, statuses and the Haulboard issue property), only while a user is viewing a Haulboard page or asking the Haulboard Rovo agent a question.
- **What it stores:** downtime details are saved as a Jira issue property on the user's own Jira site. Haulboard has no servers, no external storage, no analytics and no network egress; nothing leaves Atlassian's platform.
- **Personal data:** Haulboard does not copy or keep personal data (such as Atlassian account IDs) outside the customer's Jira site and does not cache data beyond a request.
- **Access:** Haulboard acts with the permissions of the signed-in user (scopes `read:jira-work`, `write:jira-work`).
- **Removal:** uninstalling the app stops all access. Issue properties written by Haulboard remain on the site with the issues, under the customer's control.
